BDD means Behavior-Driven Development. It describes application behaviour from the user/business perspective instead of describing implementation details.
Gherkin is the plain-text language commonly used for BDD scenarios:
Given — starting condition
When — user action
Then — observable expected result
And — continuation of the previous step
Gherkin scenarios live in .feature files. Cucumber’s official Gherkin reference
Your current use of test.step() is BDD-style reporting, but it is not Gherkin. Playwright does not parse .feature files by itself. A tool such as playwright-bdd converts Gherkin scenarios into native Playwright tests while retaining fixtures, traces, reports, parallel execution, and auto-waiting. Playwright-BDD repository
Suggested structure
features/
├── customer-purchase.feature
└── steps/
    └── customer-purchase.steps.ts
Gherkin feature
features/customer-purchase.feature:
@e2e @purchase
Feature: Customer product purchase

  As a customer
  I want to purchase a product
  So that it can be delivered to my selected country

  Scenario: Customer purchases a Blackberry successfully
    Given the customer is on the practice form
    When the customer submits valid personal details
    Then the form submission should be successful

    When the customer adds "Blackberry" to the cart
    And opens the cart
    Then the cart should contain one "Blackberry" priced "50000"

    When the customer completes checkout for delivery to "India"
    Then the purchase should be confirmed
Notice that the feature describes business behaviour. It does not mention selectors such as .navbar-toggler, #country, or tbody tr. Those technical details belong in step definitions.
Playwright step definitions
features/steps/customer-purchase.steps.ts:
import { expect } from "@playwright/test";
import { createBdd } from "playwright-bdd";

const { Given, When, Then } = createBdd();

const customer = {
  name: "badshah",
  email: "badshah@123",
  password: "Usually@12",
  dateOfBirth: "2024-06-10",
};

Given("the customer is on the practice form", async ({ page }) => {
  await page.goto("https://rahulshettyacademy.com/angularpractice/");
});

When(
  "the customer submits valid personal details",
  async ({ page }) => {
    const nameInput = page.locator('form input[name="name"]');
    const emailInput = page.locator('form input[name="email"]');
    const passwordInput = page.getByPlaceholder("Password");
    const iceCreamCheckbox = page.getByLabel(
      "Check me out if you Love IceCreams!",
    );
    const genderSelect = page.getByLabel("Gender");
    const employmentRadio = page.getByLabel("Employed");
    const dateOfBirthInput = page.locator('form input[name="bday"]');

    await nameInput.fill(customer.name);
    await emailInput.fill(customer.email);
    await passwordInput.fill(customer.password);
    await iceCreamCheckbox.check();
    await genderSelect.selectOption("Male");
    await employmentRadio.check();
    await dateOfBirthInput.fill(customer.dateOfBirth);

    await expect(nameInput).toHaveValue(customer.name);
    await expect(emailInput).toHaveValue(customer.email);
    await expect(iceCreamCheckbox).toBeChecked();
    await expect(genderSelect).toHaveValue("Male");
    await expect(employmentRadio).toBeChecked();
    await expect(dateOfBirthInput).toHaveValue(customer.dateOfBirth);

    await page.getByRole("button", { name: "Submit" }).click();
  },
);

Then("the form submission should be successful", async ({ page }) => {
  const successAlert = page.locator(".alert-success");

  await expect(successAlert).toBeVisible();
  await expect(successAlert).toContainText(
    "The Form has been submitted successfully",
  );
});

When(
  "the customer adds {string} to the cart",
  async ({ page }, productName: string) => {
    await page.getByRole("link", { name: "Shop" }).click();

    const productCard = page
      .locator("app-card")
      .filter({ hasText: productName });

    await expect(productCard).toBeVisible();
    await productCard.getByRole("button").click();
  },
);

When("opens the cart", async ({ page }) => {
  const shopNavbar = page.locator("nav.navbar-expand-lg");
  const navbarToggle = shopNavbar.locator(".navbar-toggler");
  const cartLink = shopNavbar.getByText(/Checkout/i);

  // Expand the responsive menu only on smaller viewports.
  if (await navbarToggle.isVisible()) {
    await navbarToggle.click();
  }

  await expect(cartLink).toBeVisible();
  await expect(cartLink).toContainText("1");
  await cartLink.click();
});

Then(
  "the cart should contain one {string} priced {string}",
  async ({ page }, productName: string, expectedPrice: string) => {
    const productRow = page.locator("tbody tr").filter({
      hasText: productName,
    });

    await expect(productRow).toHaveCount(1);
    await expect(productRow).toContainText(productName);
    await expect(productRow).toContainText("In Stock");
    await expect(productRow).toContainText(expectedPrice);
    await expect(productRow.locator('input[type="number"]')).toHaveValue("1");

    const totalRow = page.locator("tbody tr").filter({
      hasText: "Total",
    });

    await expect(totalRow).toContainText(expectedPrice);
  },
);

When(
  "the customer completes checkout for delivery to {string}",
  async ({ page }, country: string) => {
    const checkoutButton = page.getByRole("button", {
      name: "Checkout",
    });

    await expect(checkoutButton).toBeEnabled();
    await checkoutButton.click();

    const countryInput = page.locator("#country");
    const termsCheckbox = page.locator("#checkbox2");
    const purchaseButton = page.getByRole("button", {
      name: "Purchase",
    });

    await expect(countryInput).toBeVisible();

    await countryInput.fill(country);
    await termsCheckbox.check();

    await expect(countryInput).toHaveValue(country);
    await expect(termsCheckbox).toBeChecked();
    await expect(purchaseButton).toBeEnabled();

    await purchaseButton.click();
  },
);

Then("the purchase should be confirmed", async ({ page }) => {
  await expect(page.getByText(/Success! Thank you!/i)).toBeVisible();
});
Configuration
Install the integration:
npm install --save-dev playwright-bdd
Add its generated test directory to playwright.config.ts:
import { defineConfig, devices } from "@playwright/test";
import { defineBddConfig } from "playwright-bdd";

const testDir = defineBddConfig({
  features: "features/**/*.feature",
  steps: "features/steps/**/*.ts",
});

export default defineConfig({
  testDir,

  projects: [
    {
      name: "chromium",
      use: { ...devices["Desktop Chrome"] },
    },
  ],
});
Generate and run the tests:
npx bddgen
npx playwright test
BDD is most valuable when product owners, developers, and QA collaborate on business examples. If only automation engineers read the tests, native Playwright with well-named test.step() blocks is often simpler and requires less maintenance.
